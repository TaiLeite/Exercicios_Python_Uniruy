# Exercícios de Paradigmas de Linguagem de Programação em Python 🐍

Este repositório contém a resolução da lista de exercícios práticos desenvolvida para a conclusão da disciplina **Paradigmas de Linguagem de Programação em Python** do curso de Ciência da Computação na **UNIRUY**.

O objetivo deste projeto é consolidar conceitos fundamentais, intermediários e avançados da linguagem Python, explorando diferentes paradigmas como a programação estruturada, funcional e a Programação Orientada a Objetos (POO), além da manipulação e análise de dados.

## 🚀 Principais Conceitos Aplicados
* **Tratamento de Exceções Robustas:** Uso estruturado de blocos try-except para capturar falhas de sistema (FileNotFoundError, TypeError) e garantir a estabilidade das aplicações.

* **Manipulação de Arquivos e Formatos:** Leitura e escrita de arquivos de texto (.txt), logs dinâmicos, tabelas estruturadas (.csv) e arquivos de troca de dados no padrão Web (.json).

* **Programação Orientada a Objetos (POO):** Criação de arquiteturas baseadas em classes, métodos, associação de objetos e proteção de dados sensíveis utilizando Encapsulamento (atributos privados __).

* **Ciência de Dados (Data Science):** Utilização do ecossistema de análise de dados do Python para carregar DataFrames, calcular métricas estatísticas (médias, frequências e indexação máxima) e realizar filtragens booleanas complexas.

* **Web Scraping:** Desenvolvimento de mineradores de dados automatizados na internet utilizando requisições HTTP (requests) e parseamento de árvores HTML (BeautifulSoup).

## 🛠️ Tecnologias e Bibliotecas Utilizadas

O projeto foi desenvolvido em Python 3 utilizando as seguintes ferramentas e bibliotecas:

* Pandas — Para engenharia e manipulação ágil de dados.
* Matplotlib — Para plotagem de gráficos e visualização estatística.
* BeautifulSoup4 — Para extração e raspagem de dados de páginas web.
* Requests — Para o envio de requisições HTTP estruturadas.
* Bibliotecas Nativas: json, csv, datetime, random, string e re (Expressões Regulares).
